One-stack ritual

Login → configure → secrets → deploy → health. Same order every production ship.

  1. Login Provider CLI session
  2. Configure D1 / project link
  3. Secrets Documented Worker names
  4. Deploy Scoped providers only
  5. Health orbit status + curl

Failure honesty

When a step fails, Orbit stops and writes failure.json — not a blank terminal. Read it, fix the step, retry.

From .orbit/runs/…/failure.json

  • auth.required → orbit login … then orbit retry
  • secrets.missing → orbit secrets --put …
  • deploy.failed → step logs, fix provider error, retry
