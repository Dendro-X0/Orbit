Ship workflow

orbit ship (or plain orbit in a TTY) guides deploy by scope so you only log into providers you are shipping. Requires an interactive terminal.

When to use ship vs bare deploy

SituationPrefer
First deploy, monorepo, unclear scopeorbit ship
Re-run prepare + deploy for saved scopeorbit ship
Scripted single providerorbit deploy --provider …
Intentionally deploy every detected providerorbit deploy

Project type

ChoiceWhenProviders
API / backendWorkers API, Fly appOne backend provider
Static site / docsDocs or static frontendOne frontend provider
Full-stackAPI and docs in one sessionBackend + frontend

Monorepos may suggest full-stack, but the default selection stays API / backend so you are not forced into Vercel login.

Provider

Detection uses wrangler.toml, vercel.json, fly.toml, and netlify.toml. Full-stack may ask you to confirm deploying to multiple providers.

Action menus

First time: Ship — prepare and deploy, Change scope, Log in, Configure, Set worker secrets, Deploy, View status, Quit.

Already deployed: Open live URLs, View status, secrets if gaps remain, Change scope, Log in, Configure, Re-deploy (not recommended) with confirmation, Quit.

Prepare and deploy

  1. Ensure CLI login for selected providers (asks before browser OAuth)
  2. Configure (Cloudflare may create D1 and patch database_id)
  3. Prompt for missing Worker secrets (cancel aborts deploy)
  4. Deploy in stack order; CF+Vercel can auto-wire VITE_API_URL
  5. Offer to open live URLs on success

You may see two re-deploy confirmations: one from the ship menu, one from the deploy path.

Scope file

{
  "environment": "production",
  "ship": {
    "intentId": "api_backend",
    "label": "API / backend — Cloudflare",
    "providers": ["cloudflare"]
  }
}

ship.providers drives scoped status and configure. Change scope from the ship menu.

Full-stack notes

Deploy order is Cloudflare → Fly → Vercel → Netlify. API-only Cloudflare is the dogfooded path in v0.2.x; treat full-stack as beta until you run both providers end to end.

Full detail: docs/ship.md.
