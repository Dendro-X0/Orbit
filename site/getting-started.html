Getting started

Install Orbit from source, run orbit ship in your project, then use status and secrets to finish production readiness.

Install

Clone the repo and build a versioned binary:

git clone https://github.com/Dendro-X0/Orbit.git
cd Orbit
make build
./orbit version

Add the binary to your PATH, or call it by full path from other projects.

First deploy

From the project you want live:

cd /path/to/your-project
orbit ship
  1. Choose API / backend, Static site / docs, or Full-stack
  2. Pick the provider for that scope
  3. Log in, configure, set secrets, then deploy

Orbit stores the scope in .orbit/state.json. Later status and configure follow that intent.

After deploy

orbit status
orbit secrets
orbit open --target api

Status recommends missing Worker secrets, localhost-only CORS, and the health URL detected from your API source when possible.

Production checklist

  1. orbit ship with the intended scope
  2. orbit doctor for scoped CLIs and auth
  3. orbit configure for D1 / project links
  4. orbit secrets until required secrets are set
  5. Deploy via Ship or orbit deploy --provider …
  6. orbit status shows a live URL without blocking next steps
  7. Update CORS_ORIGINS when a production docs URL exists
  8. Hit the health route Orbit prints

Need the long form? See the markdown guides in docs/ on GitHub.
