Getting started

Build Orbit, run orbit ship in your app repo, then use status and secrets until production is clean.

Prerequisites

  • Go 1.25+ to build from source
  • Interactive terminal for orbit ship
  • Provider CLIs on PATH: wrangler, vercel, fly/flyctl, and/or netlify

Install

git clone https://github.com/Dendro-X0/Orbit.git
cd Orbit
make build
./orbit version

Put the binary on your PATH, or call it by full path. Override the project root with orbit --path /path/to/project ….

First deploy

From the project you want live (not necessarily the Orbit source tree):

orbit doctor
orbit ship
  1. Choose API / backend, Static site / docs, or Full-stack (default stays API when both API and docs are detected)
  2. Pick the provider for that scope
  3. Choose Ship — prepare and deploy: login → configure → secrets → deploy

Scope is stored in .orbit/state.json. Status and configure follow that intent afterward.

After deploy

orbit status
orbit secrets
orbit open --target api

Status recommends missing Worker secrets, localhost-only CORS, docs deploy when relevant, and a health URL detected from your API source when possible.

Scope vs bare deploy

Bare orbit deploy (no --provider) deploys the full detected stack, not only the ship scope. Prefer orbit ship or orbit deploy --provider cloudflare for a single provider.

Production checklist

  1. orbit ship with the intended scope
  2. orbit doctor for scoped CLIs and auth
  3. orbit configure (Cloudflare needs D1 database_name in wrangler.toml)
  4. orbit secrets until required secrets are set
  5. Deploy via Ship or orbit deploy --provider …
  6. orbit status shows a live URL without blocking next steps
  7. Update CORS_ORIGINS when a production docs URL exists, then re-deploy the Worker
  8. Hit the health route Orbit prints
