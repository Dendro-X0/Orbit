Run artifacts

Each deploy writes .orbit/runs/<timestamp>/ and updates .orbit/latest:

  • combined.log: full session (secrets redacted)
  • steps/*.stdout.log / *.stderr.log: per-phase logs
  • manifest.json: phases, timings, exit codes
  • summary.json: success outcome + URLs
  • failure.json: failed step, hint, log paths for orbit retry

See state-and-runs.md and auth.md.
