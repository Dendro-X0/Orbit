Configure, deploy, retry, wire

Non-ship entry points for setup and deploy. Configure follows ship scope; bare deploy hits the full detected stack.

Configure

orbit configure
orbit configure --provider cloudflare
orbit configure --dry-run --yes

Without --all or --provider, configure follows the active ship scope. Cloudflare configure requires D1 database_name and may create the database and patch database_id.

Deploy

orbit deploy --provider cloudflare
orbit deploy

Bare orbit deploy deploys every detected provider in order: Cloudflare, Fly, Vercel, Netlify. It does not use ship scope.

Retry

orbit logs --failed
orbit retry
orbit retry --from-step cloudflare-deploy

Reads failure.json, slices the plan from the failed step, writes a new run directory.

Wire

orbit wire sets VITE_API_URL on Vercel from the last Workers URL. Full-stack CF+Vercel deploys insert an automatic wire step before Vercel deploy.
