Secrets and status

Cloudflare Worker secrets and scoped status keep production honest without dumping provider CLI noise.

Document secrets

# Secrets (set via `wrangler secret put`):
# API_KEY_PEPPER, GITHUB_TOKEN

Check and set

orbit secrets
orbit secrets --put API_KEY_PEPPER

If wrangler secret list fails, Orbit treats all documented secrets as missing. Fix auth or --path, then re-check.

What status shows

  • Scoped auth and configured targets
  • Last deploy for this scope (URLs, run dir)
  • Last failure when newer than last success
  • Recommended next: secrets, CORS, docs deploy, health URL

CORS

CORS_ORIGINS lives under [vars] in wrangler.toml. After editing, re-deploy the Worker.
