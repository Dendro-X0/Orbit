What Orbit owns

Official provider tools still run auth and deploy. Orbit wraps them into one UX with phased runs, synchronized logs, and failures agents can read.

  • 1
    Scope first Choose API, static site, or full-stack before providers. Defaults stay API-only when both Worker and docs are detected.
  • 2
    Skip finished work Existing CLI sessions and prior successful deploys short-circuit busywork. Re-deploy asks for confirmation.
  • 3
    Leave a paper trail Every run writes .orbit/runs/ with logs, summary, and failure.json for orbit retry.
