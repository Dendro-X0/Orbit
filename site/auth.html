Auth and login

Orbit hands off to provider CLIs for OAuth, or stores API tokens in the OS keychain for headless use.

Login methods

ContextCommand
Local laptoporbit login <provider>
All detected providersorbit login --all
Manual token pasteorbit login --guide
CI / scriptingorbit login --token -

Interactive OAuth

Default flow: confirm, then provider CLI login, then WhoAmI. Ship and configure use the same helper and skip providers that already have a CLI session.

Tokens and keychain

Orbit maps keychain tokens to CLOUDFLARE_API_TOKEN, VERCEL_TOKEN, FLY_API_TOKEN, and NETLIFY_AUTH_TOKEN. Failed WhoAmI deletes a bad token.

Logout

orbit logout clears Orbit keychain tokens only. Run wrangler logout or vercel logout to clear provider OAuth sessions.
