Troubleshooting

Fix the failing step, read .orbit/runs/, then orbit retry or re-run the scoped command.

Doctor fails

  1. Install the scoped provider CLI
  2. Confirm it is on PATH
  3. orbit login <provider>
  4. Re-run orbit doctor

Deploy failed

orbit logs --failed
orbit retry

Hints in failure.json: auth.required, cli.missing, secrets.missing, deploy.failed.

Wrong providers deployed

Bare orbit deploy ignores ship scope. Use orbit deploy --provider … or ship deploy actions.

Worker 500 / 1101 / health 404

  • 500 / 1101: missing required secret (for example API_KEY_PEPPER)
  • 404 on health: wrong path; use the URL from orbit status (often /v1/health)
