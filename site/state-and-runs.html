State and run artifacts

Project intent lives in .orbit/state.json. Every deploy writes a timestamped run folder agents can read.

Directory layout

.orbit/
  state.json
  latest
  runs/2026-09-02T06-35-20Z/
    combined.log
    manifest.json
    summary.json
    failure.json
    steps/

state.json

{
  "environment": "production",
  "ship": {
    "intentId": "api_backend",
    "label": "API / backend — Cloudflare",
    "providers": ["cloudflare"]
  },
  "providers": {
    "cloudflare": { "targetId": "api", "configured": true }
  }
}

Artifacts

  • combined.log: full session (secrets redacted)
  • manifest.json: steps, timings, exit codes
  • summary.json: success URLs
  • failure.json: failed step, hint, log paths

Retry entrypoint

orbit retry uses failure.json from .orbit/latest. Step IDs include cloudflare-deploy, wire-vite-api-url, and vercel-deploy.
